# Contrato da UI do M5 (AG00) — citado pelos BRF-033 e BRF-034
- **Direção:** A, fantasia ornamentada (decisão 38). Referência visual: `docs/mockups/ui-direcoes.html` (seção A).
- **Peças de UI (chaves):** `ui_panel` (painel de pedra com moldura de ferro e cantos dourados, 9-slice), `ui_panel_dark` (fundo interno rebaixado, 9-slice), `ui_btn_primary` (botão dourado em relevo, 9-slice), `ui_btn_secondary` (botão de ferro, 9-slice), `ui_btn_action` (botão ciano, ex.: Recolher, 9-slice), `ui_ribbon` (fita vermelha de título, 3-slice horizontal), `ui_card_lightning`, `ui_card_fire`, `ui_card_spectral`, `ui_card_core` (moldura de carta de runa por sinergia, 9-slice), `ui_hud_bar` (barra do HUD, 9-slice), `ui_gem_lightning`, `ui_gem_fire`, `ui_gem_spectral`, `ui_gem_core` (losango do topo da carta), ícones `ui_icon_coin`, `ui_icon_heart`, `ui_icon_pause`, `ui_icon_gear`, `ui_icon_sound`, `ui_icon_sound_off`, `ui_icon_star`, `ui_icon_sword`.
- **Arquivos:** `public/assets/ui/<chave>.webp`. Insets do 9-slice em `public/assets/ui/ui.json` (`{ "<chave>": { "slice": [top, right, bottom, left], "width": n, "height": n } }`).
- **No CSS (AG02):** cada peça é uma variável em `src/styles/ui-skin.css` (ex.: `--ui-panel`, `--ui-btn-primary`) usada via `border-image`/`background`, com **fallback em CSS puro** como no mockup. Trocar a peça (T-039) = só preencher a variável/arquivo, sem mexer no layout. A UI só usa uma imagem se o arquivo estiver em `AVAILABLE_ASSETS` (`src/core/assetManifest.ts`).
